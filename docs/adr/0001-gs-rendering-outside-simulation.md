# GS Rendering Kept Outside Simulation State

**Status: accepted, revised 2026-11-22.** The first version (2026-11-21) relied on a PS2Recomp shader backend that does not exist: upstream only has a CPU rasteriser. See [ticket 16](../wayfinder/base-to-playable-fight/tickets/16-gs-vu1-approach.md).

_PT-BR: **Situação: aceita, revisada em 22/11/2026.** A primeira versão (21/11/2026) contava com um backend de shaders do PS2Recomp que não existe: o oficial só tem um rasterizador na CPU. Ver o ticket 16._

The port draws the PS2 Graphics Synthesizer (GS) with PCSX2's hardware renderer (`pcsx2gs.dll`, DX11/DX12), taken as a single piece from the PS2Recomp-Fixer fork into our PS2Recomp fork. The runtime feeds it the GIF command stream and the end of each field on its own thread. The game never reads from the GS, so all GS and GPU state stays outside the savestate buffer that rollback netplay serializes, and draws stay suppressed while frames are resimulated during rollback. VU1 is not emulated; a guard logs and stops on any VU1 microprogram upload or PATH1/PATH2 packet. Drawing selected layers natively from the game's own data is a later extension on top of this renderer, not a replacement for it.

_PT-BR: O port desenha o Graphics Synthesizer (GS) com o renderizador por hardware do PCSX2 (`pcsx2gs.dll`, DX11/DX12), trazido como peça única do fork PS2Recomp-Fixer para o nosso fork do PS2Recomp. O runtime entrega a ele o fluxo de comandos do GIF e o fim de cada campo, numa thread própria. O jogo nunca lê do GS, então todo o estado do GS e da placa de vídeo fica fora do buffer que o rollback salva, e o desenho fica suprimido enquanto o rollback refaz quadros. A VU1 não é emulada; uma guarda registra e para em qualquer envio de microprograma da VU1 ou pacote PATH1/PATH2. Desenhar camadas escolhidas direto dos dados do jogo é uma extensão futura por cima desse renderizador, não um substituto._
