# KOF XI Recomp

A native PC port of The King of Fighters XI, produced by statically recompiling an original console release.

_PT-BR: um port nativo para PC de The King of Fighters XI, produzido pela recompilação estática de uma versão original de console._

## Language / Linguagem

**Base Version**:
The single original console release whose machine code the project recompiles.
_Avoid_: source version, target version, original build
This project's Base Version is the PS2 Release (US edition).

_PT-BR — **Versão-base**: a única versão original de console cujo código de máquina o projeto recompila. Neste projeto, a versão de PS2 (edição americana)._

**Arcade Release**:
The original KOF XI released by SNK Playmore on the Atomiswave arcade platform.
_Avoid_: Atomiswave version, Flycast version, Dreamcast version

_PT-BR — **Versão de arcade**: o KOF XI original lançado pela SNK Playmore na plataforma de arcade Atomiswave._

**PS2 Release**:
The official PlayStation 2 release of KOF XI, with fighters, modes and menus the Arcade Release lacks.
_Avoid_: console version

_PT-BR — **Versão de PS2**: o lançamento oficial de KOF XI para PlayStation 2, com lutadores, modos e menus que a versão de arcade não tem._

**Dreamcast Conversion**:
An unofficial fan-made disc that runs the Arcade Release's code on a Dreamcast; it is not a separate release.
_Avoid_: Dreamcast version, Dreamcast port

_PT-BR — **Conversão para Dreamcast**: disco não oficial, feito por fãs, que roda o código da versão de arcade num Dreamcast; não é um lançamento à parte._

**Arranged Option**:
The PS2 Release's setting that, when on, brings its new stages, rearranged music and rebalancing to the whole game; when off, the game plays with the Arcade Release's balance, keeping the PS2-only fighters and Color Edit.
_Avoid_: Arrange Mode, arranged version

_PT-BR — **Opção Arranged**: ajuste da versão de PS2 que, ligado, traz as fases novas, as músicas rearranjadas e o balanceamento novo para o jogo inteiro; desligado, o jogo usa o balanceamento da versão de arcade, mantendo os lutadores exclusivos do PS2 e o Color Edit._

**User-supplied Disc**:
A disc image of the game that each user dumps from their own copy and provides locally; the project never distributes it.
_Avoid_: ROM, ISO (as a general term), game files

_PT-BR — **Disco do usuário**: imagem de disco que cada usuário extrai da própria cópia e fornece localmente; o projeto nunca a distribui._

**Complete Fight**:
One full match between two teams, from the start of round one to the result screen, with graphics, sound, music and controller input.
_Avoid_: match, round, playable build

_PT-BR — **Luta completa**: uma partida inteira entre dois times, do início do primeiro round até a tela de resultado, com gráfico, som, música e controle._

**Hidden Character**:
A fighter that exists in the Base Version's data but is not selectable in normal play, such as a boss or sub-boss.
_Avoid_: secret character, unlockable, extra character

_PT-BR — **Personagem oculto**: lutador que existe nos dados da versão-base mas não é selecionável normalmente, como chefe ou sub-chefe._

**New Character**:
A fighter added to the port that does not exist in the Base Version, including fighters brought over from Neo Geo Battle Coliseum.
_Avoid_: extra character, custom character

_PT-BR — **Personagem novo**: lutador adicionado ao port que não existe na versão-base, incluindo os trazidos do Neo Geo Battle Coliseum._

**Reference Emulator**:
The emulator running the Base Version that serves as the ground truth for how the port must behave.
_Avoid_: oracle, golden emulator

_PT-BR — **Emulador de referência**: o emulador rodando a versão-base que serve de gabarito para como o port deve se comportar._
